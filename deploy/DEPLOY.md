# Деплой Руссо

Сайт стоит на том же VPS Timeweb, что и ADSmart: сервер **Honest Macaw**, адрес **72.56.89.69**.

Руссо открывается только так: **http://72.56.89.69:8080/**

Адрес без порта, http://72.56.89.69/ и https://ad-smart.ru/ — это ADSmart. Его эта выкладка не заменяет.

Выкладка идёт с вашего компьютера по SSH. GitHub Actions и старый сервер Beget больше не используются.

## Обновления

`npm run deploy:beget` выкладывает обновления. Команда берёт проект Руссо в том виде, в каком он сейчас открыт в PyCharm, в том числе коммиты, которые ещё не отправлены на GitHub. Сайт на сервере собирается заново и целиком заменяется по адресу http://72.56.89.69:8080/.

ADSmart эта команда не меняет.

## Один раз

В корне проекта `D:\PycharmProjects\Russo` лежит файл `.env.server`. Его не коммитят. Внутри четыре строки:

```
SSH_HOST=72.56.89.69
SSH_USER=root
SSH_PASSWORD=пароль root
SSH_PORT=2222
```

Порт **2222** обязателен с этого компьютера: провайдер обрывает исходящие соединения на порт 22. На сервере SSH слушает оба порта, 22 и 2222.

В файрволе Timeweb, группа **Humble Pheasant** на Honest Macaw, должны быть входящие TCP-порты: **22**, **2222**, **80**, **443**, **8080**. Новые порты для следующих выкладок Руссо не нужны.

В PyCharm должна быть открыта ветка **beget**. Скрипт останавливается, если текущая ветка другая.

## Каждый деплой

1. Откройте в PyCharm проект **Russo**, не ADSmart.
2. Внизу откройте **Terminal**.
3. Выполните:

```bash
npm run deploy:beget
```

Дождитесь строки:

```
site=http://72.56.89.69:8080/
```

Открывайте именно её. Предупреждение Git про `LF will be replaced by CRLF` на выкладку не влияет.

## Что делает команда

1. Проверяет, что текущая ветка — `beget`.
2. Добавляет изменения в git, коммитит их с сообщением `deploy: update Russo`, если они есть, и отправляет ветку `beget` на GitHub. Файл `.env.server` в коммит не попадает.
3. Собирает сайт (`npm run build`).
4. По SSH заходит на сервер через порт **2222**.
5. Пишет конфиг nginx только на порт **8080** и перезагружает nginx. Сайт ADSmart на портах 80 и 443 и бот не перезапускаются.
6. Заливает собранный `dist/` в `/var/www/russo`.

Проверка связи без сборки и без заливки:

```bash
python deploy/deploy-beget.local.py check
```

В ответе должно быть `nginx=yes` и `site=yes`.

## Если команда остановилась

**`active branch is ... expected beget`.** Внизу PyCharm переключитесь на ветку `beget` и запустите команду снова.

**`SSH ... не открывается`.** В `.env.server` должна быть строка `SSH_PORT=2222`. В группе Humble Pheasant должен быть входящий TCP **2222**. На сервере SSH должен слушать этот порт: в веб-консоли Timeweb команда `ss -lnt | grep 2222` показывает `:2222`.

**Сайт открылся, но это ADSmart.** В адресе нет `:8080`. Нужен http://72.56.89.69:8080/
