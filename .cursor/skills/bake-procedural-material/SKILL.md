# Bake procedural material → PBR textures for GLB

## Когда применять
Материал сделан через процедурные ноды в Blender (Noise, ColorRamp, Mix Shader
и т.д.) и должен попасть в браузер через GLB. Процедурные ноды не экспортируются —
нужен набор растровых текстур.

## Шаги

1. **Определить разрешение.** Для мелких декоративных элементов (шильдик,
   рёбра, накладки) обычно достаточно 1024–2048px. Для крупных панелей
   (двери, корпус) — 2048–4096px.

2. **Подготовить UV.** Убедиться, что объект развёрнут (unwrap) без наложений
   швов на видимых зонах. Если развёртки нет — сделать её первой.

3. **Создать image texture nodes** для каждого нужного канала (Base Color,
   Roughness, Metallic, Normal, при необходимости AO/Emissive), назначить им
   новое пустое изображение нужного разрешения.

4. **Bake через Cycles**: в свойствах рендера переключиться на Cycles →
   Bake, для каждого канала выбрать соответствующий тип (Diffuse только
   Color для Base Color, Roughness, Normal, и т.д.), убедиться что выбран
   активный image node перед каждым bake.

5. **Экспортировать изображения** (PNG, без сжатия с потерями для Normal
   map — обязательно PNG, не JPEG).

6. **Назначить в Principled BSDF** — подключить запечённые текстуры в
   стандартный Principled BSDF node (только он поддерживается glTF-экспортом
   один-в-один), убрать/отключить старые процедурные ноды либо оставить их
   в отдельном материал-слоте только для превью в Blender.

7. **Проверить экспорт** — экспортировать GLB, открыть в
   https://gltf-viewer.donmccurdy.com/ или локальном R3F-дев-сервере,
   сверить визуально со скриншотом из Blender.

## Частые ошибки
- Забыли переключить color space Base Color текстуры на sRGB, а
  Roughness/Metallic/Normal — на Non-Color/Linear.
- Bake прошёл с активным неправильным image node (перезаписали не ту карту).
- Normal map экспортирована в OpenGL-конвенции, а Three.js ожидает
  DirectX-конвенцию (или наоборот) — если normal выглядит "вдавленным",
  проверить это в первую очередь.
